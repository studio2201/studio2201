# Section 10 · Release cadence



- `0.1.0` ships with one verb, one demo, one README, three integration tests.
- `0.2.0` swaps a placeholder for a real input pipeline (e.g., Boneyard's risk axis stops being a name-length proxy).
- `0.x.0` accumulates small breaking fixes only when the loop is broken.
- `1.0.0` ships when a Fortune 500 CISO has used the binary in production and the README's "Status: scaffold" line gets removed.

A version is a contract. `0.x.y` means the loop is honest but the surface is moving. `1.0.0` means the surface has stabilized enough that buyers can integrate it into a 5-year procurement plan.
